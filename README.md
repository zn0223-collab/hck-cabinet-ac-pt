# Como escolher um ar-condicionado de armário para gabinetes industriais

Guia prático de dimensionamento para quadros elétricos, telecom, baterias e cabines.

Acima de ~40°C de ambiente, a ventoinha não basta. O **circuito fechado** (compressor, IP55) mantém 25–35°C e exclui poeira/umidade.

## Dimensionamento
- Pequeno (<2 m3): **3000 W**
- Médio (2–4 m3): **5000 W**
- Grande/container (>4 m3): **7500 W**

## O que importa
- IP55 para exterior e indústria
- Funciona **de -40°C a +55°C**
- R410A + microcanal (~30% mais eficiente)
- RS485/Modbus remoto
- desde 52 dB, sem ferramentas
